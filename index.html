브라우저에 저장 · 기기 간 자동 동기화 안 됨

공고를 직접 추가하면 이 브라우저에 저장돼. 다른 사람에게 HTML 파일을 보내도 네가 추가한 데이터는 자동으로 전달되지 않으니 JSON 백업을 함께 공유해야 해.

향후 자동연동용 데이터 구조
수집기/API → 표준 JSON 변환 → 검증·중복 제거 → 저장소/정적 JSON 배포 → 웹 캘린더 반영
필수 필드: id, title, agency, region, type, targets[], start, end, detailUrl, sourceUrl, verifiedAt, isSample=false.
기관별 공식 API/수집 가능 여부, 갱신 실패 표시, 수정공고 처리, 특별공급·1순위 등 접수 구간 분리가 후속 개발 범위야. 현재 이 파일에는 수집기·서버·예약 실행 기능이 없어.

주의: 이 캘린더는 청약 자격이나 당첨 가능성을 판단하지 않아. 신청 전 공식 공고문과 접수 마감 시각을 반드시 확인해 줘.
